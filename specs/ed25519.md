# `Ed25519` — RFC 8032 key derivation, signing and verification

## Documentation

| Call | Meaning |
|---|---|
| `Ed25519.verify(publicKey, message: m, signature: s)` | whether `s` is a valid Ed25519 signature of `m` under the 32-byte `publicKey` |
| `Ed25519.publicKey(privateKey)` | the 32-byte public key of a 32-byte private key (RFC 8032 section 5.1.5) |
| `Ed25519.sign(privateKey, message: m)` | the 64-byte signature `R ‖ S` of `m` under a 32-byte private key (RFC 8032 section 5.1.6) |

`publicKey` and `sign` throw `Ed25519Error.invalidLength` when the private key is not exactly 32 bytes; a 64-byte
expanded key is refused, and an all-zero or all-ones key is valid because it is hashed before use. Both
multiply the base point by the clamped half of the key's SHA-512 digest in time independent of the key.

`verify` throws `Ed25519Error.invalidLength` when the public key is not exactly 32 bytes or the signature not
exactly 64. Any other key or signature is answered with a `bool`: it is `true` only when the cofactorless equation
`[S]B = R + [k]A` holds, with `k` the SHA-512 digest of `R`, the public key and the message reduced mod `L`. A
public key or `R` that does not decode, including a `y` at or above `2^255 - 19` and `x = 0` with the sign bit set,
and an `S` at or above `L`, are `false`.

The vectors are RFC 8032 section 7.1, Project Wycheproof's Ed25519 cases, changed and mixed-order signatures,
and the canra `ed25519-sign` contract's keys and signatures. Each line prints a vector's id and the answer,
or the error.

function digit(symbol Byte) returns Byte
	if symbol >= 0x61 'letter'
		return symbol - 0x57
	end 'letter'

	return symbol - 0x30
end 'digit'

function fromHex(hex String) returns ByteArray
	var bytes = ByteArray.create()
	var high = 0 as Byte
	var isHigh = true

	for symbol in hex.bytes() 'eachSymbol'
		if isHigh 'first'
			high = digit(symbol)
		end 'first' else 'second'
			bytes.push(high * 16 + digit(symbol))
		end 'second'

		isHigh = not isHigh
	end 'eachSymbol'

	return bytes
end 'fromHex'

function errorName(failure Ed25519Error) returns String
	return match failure 'name'
		invalidLength gives "invalidLength"
	end 'name'
end 'errorName'

function report(id String, publicKeyHex String, messageHex String, signatureHex String)
	if let valid = try Ed25519.verify(fromHex(publicKeyHex), message: fromHex(messageHex), signature: fromHex(signatureHex)) 'done'
		print("{id} {valid}\n")
	end 'done' else (failure) 'refused'
		print("{id} {errorName(failure)}\n")
	end 'refused'
end 'report'
