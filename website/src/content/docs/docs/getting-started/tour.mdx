[Your first program](/docs/getting-started/first-program/) showed the language one feature at a time.
This page reads a whole program instead: `examples/wc.maxon`, a working replacement for Unix `wc`
that counts its files on every processor of the machine.

It is the file you can read on the [Examples](/examples/) page, unedited. **The program carries no
comments** — the code is meant to answer for itself, and a tour is where the *why* belongs. Read the
left column top to bottom and you will have read the whole program.

## What it does

```
wc [flags] FILE...
```

It prints the lines, words and bytes of every `FILE`, and their total when there is more than one.
`-l`, `-w` and `-c` choose which of those columns to print; with no flag it prints all three.

```
$ wc a.txt b.txt
       3       9      47 a.txt
       2       3      16 b.txt
       5      12      63 total
```

A word is a run of bytes that are not whitespace, and a line is a line feed — the counts `wc`
documents. It exits `0` normally and `1` when a flag is wrong or a file cannot be read.

## Names first

<TourStep from={1} to={25}>
The file opens with nothing but names.

The first two are **[ranged type aliases](/docs/language/ranged-typealiases/)**. A number in a type
position states the values it may hold: `WorkerCount = int(1 to 64)` cannot hold `0`, so no code that
receives one has to wonder whether it is about to start no workers at all.

The rest are **container aliases**. A generic type is instantiated by naming it — `Array with FilePath`
— and always through an alias, so every container in the program wears a domain name. `Column` is a
**function type**: a value that takes some `Counts` and gives a number. `Counter.handle` names a
service that the program has not started yet. See [Collections](/docs/stdlib/collections/).

**Enums can carry a value.** `Outcome` gives the exit codes names; `Whitespace` names the bytes the
word scanner treats as gaps, so it never compares against a bare `0x20`.
</TourStep>

<TourStep from={27} to={61}>
Two more enums, and both do work.

`Flag`'s raw values are **the strings a person types**. That is the whole flag table: the spelling,
the help text in `summary()`, and in `column()` what the flag selects.

`column()` returns a **closure** — a function written as a value. Each of the three picks one field
out of a `Counts`. The rest of the program holds them as `Column`s and never asks which is which.

Every body here is one `match` **expression**: `match self 'describe' … end 'describe'` produces a
value, each arm using `gives`. Every case is listed and there is no `default`, so a new flag cannot be
added without its help text and its column. The label `'describe'` is repeated on `end`, which is what
keeps nested blocks readable.

`UsageError` **implements `Error`**, which is all it takes to be throwable. An error is an ordinary
enum, cheap to make and exhaustive to handle. See [Error handling](/docs/language/error-handling/).
</TourStep>

## Reading the command line

<TourStep from={63} to={95}>
`Options` is a plain record. Its fields carry **defaults**, so `Self{}` builds a complete value.
`Self` is how a type names itself; a record literal may only be written inside its own type, which
keeps construction in the type's hands. `export` on a field makes it readable outside the type.

`args.withIterator()` hands back the position and the value together, so the loop can skip the
program's own path. Each branch of the `if`/`else` **names what it decides** — `'aFlag'`, `'aFile'` —
and repeats that name on its `end`.

`try Flag.fromRawValue(text) otherwise throw UsageError.unknownFlag` is the everyday shape of error
handling: a call that can fail and, on the same line, what to do instead. The enum turns a typed string
back into a case, so an unknown flag is caught without a chain of comparisons.

The columns are chosen by walking `Flag.allCases` — generated by the compiler, in declaration order —
so `wc -w -l` prints lines before words, as `wc` does, whatever order the flags were typed in.
</TourStep>

## Counting

<TourStep from={97} to={136}>
`extension int` adds a method to a **primitive type**: `self` is the byte, and the comparisons read the
`Whitespace` constants directly, because an enum with raw values compares with the numbers it names.

`Counts` is the three numbers and the two ways to make them. `of` is the whole of counting — one pass
over the bytes, a line at each line feed, a word wherever a non-blank byte follows a blank one. `inWord`
is the only state it needs.

`content.count()` answers the array's own index type, and the `as Tally` converts it. Two aliases with
the same range are still two types — a count of bytes and a position in an array do not mix by
accident.

`add` writes the other count into this one. A method that assigns to `self`'s fields needs no marking;
records are passed by reference, so the caller's `Counts` is the one that changes.
</TourStep>

<TourStep from={138} to={152}>
**A [union](/docs/language/enums-unions/) is a value that is exactly one of several shapes, and
carries different data in each.** A file's result is either its counts, or the fact that it could not
be read — and nothing that reads a `FileCount` can reach the counts without first establishing which
it has.

**`Counter` is the type that becomes a service, and it is an ordinary type.** `export` on a method
marks the **message API**: what another thread may ask this type to do. `count` reads one file and
answers its result.

`try File.readBinary(path) otherwise return FileCount.unreadable` turns a failed read into a value
rather than an error. A file that cannot be read is an *answer*, which is why the union has a case for
it.
</TourStep>

## Reporting

<TourStep from={154} to={193}>
`Report` holds what the run has seen: the columns to print, the running total, and whether anything
went wrong.

`match result 'outcome'` takes the union apart. `counted(counts)` both *tests* the shape and *binds*
what it carries; `unreadable` has nothing to bind. The arms use `then` rather than `gives` because they
*do* something rather than produce something.

`printRow` is where the closures are spent: `column(counts)` calls whichever function the flag chose.
`{column(counts):8}` is **string interpolation** with a format specifier — the value, right-aligned in
eight places. A `StringBuilder` collects the row so it is printed once.
</TourStep>

## Using the processors

<TourStep from={195} to={226}>
**`spawn` turns a type into a service running on its own green thread**, scheduled across the
machine's processors. `spawn Counter.create()` runs the factory over there and hands back a
`Counter.handle`. `workersFor` starts one per processor, or one per file when there are fewer files —
the `as WorkerCount` at the end is checked at run time, and `Options.parse` has already guaranteed at
least one file.

`counter.count(path.clone())` **does not block**. It posts the message and hands back a promise, so
every file is in flight before the first answer is read. Sending moves a value to the service; the
`clone()` gives it a path of its own, because `paths` still holds the original. See the
[memory model](/docs/language/memory-model/).

`try await reply` takes each answer back, **in the order the files were named**, not the order the
workers finished — so the output is the same at one worker or sixty-four. It is a `try` because the
one failure every message has is a service that is gone, and this program reports that the same way as
a file it could not read.

A service outlives the function that spawned it until someone says otherwise, so every worker is shut
down explicitly. See [Concurrency](/docs/language/async/).
</TourStep>

## Finishing

<TourStep from={228} to={252}>
`printUsage` walks `Flag.allCases` again, so the help text cannot fall behind the enum.

`try Options.parse(…) otherwise (problem) 'badUsage'` binds the error that was thrown, and the handler
block can then do several things with it before `main` returns.

`main` returns an `ExitCode`, and `Outcome.troubled` *is* one, because the enum's raw values are the
exit codes. `Outcome.troubled if report.troubled else Outcome.counted` is an **`if` expression** —
the conditional produces a value rather than choosing a statement.
</TourStep>

## Run it yourself

```
maxon build examples/wc.maxon
./examples/wc -l -w examples/*.maxon
```
